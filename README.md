# 🍽️ Zomato Restaurant Clustering using Unsupervised Machine Learning

## 📌 Problem Statement

Zomato has a large amount of restaurant data containing cost, cuisines, ratings, collections, timings, and customer reviews.  
Analyzing this data manually is difficult, so Machine Learning is used to identify similar restaurants and understand customer feedback.

## 🎯 Objective

- Group similar restaurants using Unsupervised Machine Learning.
- Compare K-Means, Agglomerative Clustering, and DBSCAN.
- Identify the best clustering model.
- Analyze customer reviews using Sentiment Analysis.
- Generate useful business insights and recommendations.

## 🤖 Machine Learning

- K-Means Clustering
- Agglomerative Clustering
- DBSCAN
- TF-IDF
- Logistic Regression

**Best Clustering Model:** DBSCAN  
**Silhouette Score:** 0.5192

## 💬 Sentiment Analysis

Customer reviews are classified into:

- 😊 Positive
- 😐 Neutral
- 😞 Negative
